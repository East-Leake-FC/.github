# east-leake-fc/.github

Organisation-wide files for [East Leake FC](https://github.com/east-leake-fc).

- [`profile/README.md`](profile/README.md) is the public profile shown on the organisation's GitHub page.
- [`profile/assets/`](profile/assets) holds the club crests it displays. They are copied from the website repo because private repositories can't serve images to a public page.

Community health files (issue templates, `CONTRIBUTING.md`, and so on) placed here apply by default to every repository in the organisation that doesn't have its own.
